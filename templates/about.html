About This Project

A login-free web application that predicts diabetes risk using machine learning.

Features
  • Login-free web application
  • Patient name and sex on reports
  • MySQL prediction history with date & time
  • Analytics dashboard with charts
  • PDF report generation
  • Bootstrap UI with icons
  • Multiple ML models with selectable accuracy
Technologies Used
Python Flask Bootstrap 5 MySQL Chart.js FPDF2 Pandas Scikit-learn

Dataset: Pima Indians Diabetes Database (768 records)
